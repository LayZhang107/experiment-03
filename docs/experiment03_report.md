# 实验三 营销数据获取与清洗报告

## 1. 实验目的

围绕咖啡品牌消费者评价建立可追溯、可复现、可用于后续分析的营销数据管线。

## 2. 数据对象

本项目选择星巴克、瑞幸、Manner和库迪四个咖啡品牌，每个品牌约100条记录，字段覆盖产品、价格、评分、评论、日期和互动数据。

## 3. 数据获取与伦理

数据为教学模拟数据，字段结构参考公开商品评价信息。数据不包含个人敏感信息，不绕过登录、验证码或付费限制。原始文件、清洗文件和处理脚本分开保存。

## 4. 清洗过程

清洗脚本依次处理重复记录、价格格式、品牌别名、评分范围、互动数、日期格式和关键字段缺失。规则写入 src/clean_data.py，可重复运行。

## 5. 结果

原始数据408条，删除8条完全重复记录和2条关键字段缺失记录，得到398条清洗数据。核心字段完整率均达到90%以上，四个品牌仍保持约100条样本规模。

## 6. 后续使用

data/processed/clean_data.csv 将作为实验四消费者洞察引擎的输入，用于统计品牌评分、价格、评论主题和消费者痛点。
